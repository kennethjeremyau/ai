# Documentation

The goal is writing for a tired engineer to understand on the first read. The steps to get there:
- **Choose document type.** Use Diátaxis approach to determine the type of document to write.
- **Use sentence style.** Use Google developer documentation style guide to address audience in a consistent manner.
- **Use professional language.** Use Simplified Technical English to reduce complexity.
- **Reduce ambiguity.** Use Global English to ensure every sentence has a single meaning.
- **Unslop.** Use the **unslop** skill so writing seems more human.
